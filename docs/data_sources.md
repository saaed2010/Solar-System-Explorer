# Scientific data notes and sources

Solar System Explorer uses a compact, educational dataset. Values are rounded for legibility; they are not intended for mission navigation or professional ephemeris work.

## Scale convention

All comparison calculations use diameter in kilometres. Stellar diameters are converted from published radius ratios with the IAU nominal solar radius of exactly 695,700 km, so the nominal solar diameter used by the engine is 1,391,400 km. A radius ratio and diameter ratio are numerically identical only when both values use the same convention; the interface consistently labels the result as a **diameter ratio**.

Stars are not rigid spheres. Their reported radii can change with wavelength, pulsation, distance estimates, rapid rotation, and atmospheric models. These entries are explicitly labelled approximate in the app. Betelgeuse uses the representative 1,000-solar-radius value adopted in NASA/Hubble educational material; UY Scuti uses a conservative representative estimate of 909 solar radii and is marked as substantially uncertain.

Planet diameters shown in the catalog use NASA equatorial values where the source publishes those values. Small irregular bodies use representative or mean-equivalent diameters and are labelled approximate.
